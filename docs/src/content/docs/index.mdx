grafana-tui is a terminal user interface for Prometheus dashboards. Use it to examine data fast, in SSH sessions, and to find problems on a local host. It also helps where a browser-based Grafana instance is not practical.

grafana-tui reads Prometheus directly and can import Grafana dashboard JSON files. It draws supported panels as terminal charts, tables, gauges, stats and heatmaps. The keyboard controls all of the functions.

## When grafana-tui fits

Use grafana-tui when you want:

- A lightweight Prometheus dashboard in the terminal.
- A familiar way to inspect exported Grafana dashboards.
- Fast start and low resource use.
- A dashboard that works well over SSH.
- SVG or PNG snapshots of the current TUI view.

grafana-tui does not replace a Grafana server. It does not manage users, alerts, annotations or plugins. You cannot edit a dashboard in it, and it does not show browser-only panel types. The [Grafana compatibility matrix](/grafana-tui/grafana-compatibility/) lists the supported items.
